Aktenbuddy
==========

Aktenbuddy hilft bei der Navigation durch die Aktenpläne der ELKW auf dem PC-im-Pfarramt-Rechner. 

Beim ersten Aufruf installiert sich Aktenbuddy unter "Senden an..." im Explorer. Außerdem wird der Benutzer aufgefordert, das Programm an der Startleiste festzupinnen.

Aktenbuddy kann man auf zwei Arten benutzen:

## Start aus dem Explorer (Senden an...)
Durch einen Rechtsklick auf eine beliebige Datei aus dem Explorer lässt sich "Senden an..." und dann "Aktenbuddy" auswählen. Eine Auswahl der verfügbaren Aktenpläne und die Auswahl eines Aktenzeichens erscheinen. Anschließend kann gegebenenfalls noch ein Unterordner ausgewählt und die Datei umbenannt werden. Am Ende wird die Datei automatisch in den Aktenplan verschoben.

## Start über die Startleiste
Beim Start über die Startleiste erscheint nur die Auswahl für Aktenplan und Aktenzeichen. Nach Bestätigung wird der Pfad in die Zwischenablage gewählt. Dies kann nützlich sein, wenn (z.B. unter Word, o.ä.) ein Dateifenster geöffnet ist. Ein Klick auf die Startleiste öffnet den Aktenbuddy. Nach Auswahl des Aktenzeichens kann der Pfad einfach mit Strg+V ins Dateifenster kopiert werden.
