Gottesdienste Live
==================

Eine Android TV-App zum Anschauen von Gottesdienstaufzeichnungen. Diese App greift auf ein 
[experimentelles Backend](https://codeberg.org/peregrinus/rk-wrapper) zu, das Gottesdienste u.a. von Streams von RK Solutions 
oder aus einem Youtube-Kanal bereitstellt.
